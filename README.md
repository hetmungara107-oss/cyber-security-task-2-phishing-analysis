# Cyber Security Internship — Task 2

## Analyze a Phishing Email Sample

### Objective
Identify common phishing indicators in a suspicious email sample and document the findings.

### Tools Used
- Kali Linux
- Nano text editor
- Manual email inspection
- Google Admin Toolbox Messageheader (for genuine email header analysis when available)

### Project Structure
- `samples/phishing_sample.txt` — fictional training email
- `report.md` — phishing analysis report
- `screenshots/` — screenshots documenting the work

### Indicators Analyzed
1. Lookalike sender spelling
2. Urgent and threatening language
3. Unverified verification link
4. Generic greeting
5. Missing original email headers

### Findings
The fictional email demonstrates several characteristics associated with phishing. These observations are documented in `report.md`.

### Limitations
This project uses a simulated training email. No original email headers were available, and no live links or attachments were tested. The findings are educational observations, not proof of a real phishing attack.

### Safety Precautions
- Did not open the suspicious link.
- Did not execute any attachments.
- Used a fictional email sample.

### Conclusion
This exercise demonstrates how to identify potential phishing indicators and document an investigation while distinguishing observed evidence from unverified claims.
